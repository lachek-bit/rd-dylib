## 模块职责

### RemoteDebug.m —— 核心

- **HTTP 服务**：手写 BSD socket，没引第三方库。一个 accept 线程 + 每连接一线程。
- **日志**：`NSLog`/`printf` 走 stderr，用 `pipe()` + `dup2()` 截下来，按行切分
  存内存环形缓冲（3000 条），同时异步落盘。
- **路由**：`RDHandle(method, path, query, body)` 一个大 if 链，返回 `RDResp`。
- **JavaScriptCore**：`JSContext` + 注入常用类和 `_rd` 对象。
- **截图**：`UIGraphicsImageRenderer` + `drawViewHierarchyInRect`。

### RDHook.m —— hook 引擎

核心是 `imp_implementationWithBlock`，但有两个关键设计：

**1. block 返回 `void *` 而不是 `id`**

因为要兼容「对象 / 整数 / BOOL / void」四种返回值。如果声明成 `id`，ARC 会对
伪造的整数指针做 `retain`，直接崩。`void *` 不会触发任何内存管理，调用方按自己的
类型从 x0 读，天然兼容。

**2. `_cmd` 不会传给 block**

`imp_implementationWithBlock` 的约定是 block 第一个参数接 self，**不传 `_cmd`**。
所以 `_cmd`（也就是 SEL）提前存在规则对象里，转发原实现时用它。

**参数转发**：block 声明 6 个 `id` 参数，覆盖 arm64 上前 6 个寄存器参数。
整数参数按位转发（寄存器内容不变），对象参数正常传递。超过 6 个参数的方法只能
`skip`/`force`（不转发原实现），不能 `log`。

**拒绝的类型**：返回结构体的方法直接拒绝（`{` 开头），因为不知道大小，会踩内存。
浮点返回单独用 `double` block。

### RDAutomation.m —— 触摸注入

两条路，都实现：

1. **IOHIDEvent**（真实触摸）：`dlopen` IOKit，`dlsym` 拿
   `IOHIDEventCreateDigitizerEvent` / `IOHIDEventCreateDigitizerFingerEvent` /
   `IOHIDEventSystemClientDispatchEvent` 等。构造 hand + finger 事件，先 down 再 up。
   对 WebView / 游戏 / 自定义手势都有效。

2. **UIControl sendActions**（精确）：往上找最近的 `UIControl`，发
   `TouchDown` + `TouchUpInside`。对标准按钮最稳，无私有 API。

`RDTapView` 先试 2 再补一发 1，两者都做。

`RDInteractiveTree` 递归遍历视图树，挑出「可点击 / 有文字」的节点，输出序号、
类名、文字、**屏幕坐标中心点**。这是 AI 找按钮的主要依据。

第三条路是 **accessibilityActivate**（`ui.ax` / `ui.axTap`）：遍历
`accessibilityElementCount` / `accessibilityElementAtIndex:`，对目标元素调
`accessibilityActivate`。不依赖 IOHID、不碰系统类，但 **SwiftUI 界面通常返回 0 个元素**
（它的无障碍树要辅助功能激活才生成），见坑 14。

### 写入保护（`RDInstallWriteGuard`）

hook `NSUserDefaults` 的 `setObject:forKey:` / `setValue:forKey:`，key 命中保护列表时
**直接丢弃这次写入**。用来固化「会被 app 改回去」的配置项。

关键点：**只拦写入，不拦读取**。读取方法（`objectForKey:` / `boolForKey:`）是高频调用，
替换 IMP 会崩（见坑 12）；写入频率低，安全。

保护列表落在 `guards.json`，constructor 里 `RDLoadGuards()` 恢复，早于 app 任何代码。

### RevenueCat 权益伪造（`RDPatchRevenueCat`）

试图接管 `RCEntitlementInfos` 的 `all` / `active` / `activeInAnyEnvironment` /
`activeInCurrentEnvironment` / `objectForKeyedSubscript:`，返回一个伪造的
`{entitlementID: fake}` 字典。

**这条路实际走不通**：`RCEntitlementInfo` 是 Swift 类，`+alloc` 就拿不到合法元数据，
一碰就 SIGSEGV（坑 11）。代码留着当参考，别在 Swift 类上重试。

### RDTool.m —— 工具注册表

结构就是一个 `NSMutableDictionary<name, RDTool>`，每个 `RDTool` 有
name / title / desc / group / params / handler(block) / jsCode。

内置工具用 block 写；自定义工具用 JS 写，存 `tools.json`，每次调用时把 code 包成
`(function(){ var args = {...}; <code> })()` 丢进 JSContext 执行。

### RDFloat.m —— 悬浮球

**必须挂在 app 自己的 keyWindow 上**，不能用独立 UIWindow（见坑 3）。

用一个 `hitTest` 返回 nil 的容器视图做宿主，空白处让事件穿透给下面的兄弟视图。
按钮挂 `UITapGestureRecognizer`（点击）+ `UIPanGestureRecognizer`（拖动）+
`UILongPressGestureRecognizer`（3 秒隐藏）。

## 线程模型

| 操作 | 线程 |
|---|---|
| accept / 解析 HTTP / 组装响应 | 后台线程（每连接一个） |
| 所有 UIKit 操作 | 主线程（`RDRunOnMain` 用 `dispatch_sync`） |
| 日志落盘 | 专用串行队列 `com.rd.logwriter` |
| accept 循环 | 全局并发队列 |

**`RDRunOnMain` 的关键**：如果已经在主线程就直接执行，否则 `dispatch_sync`。
不加这个判断，主线程里调用会死锁。

## 数据持久化

全部落在 **app 沙盒的 `Documents/RemoteDebug/`**（写不了 `/var/mobile/Library`，见坑 6）：

| 文件 | 内容 |
|---|---|
| `last.log` | 滚动日志（>1MB 自动清空） |
| `crash.log` | 崩溃栈（signal + backtrace，最多 64 帧） |
| `hooks.json` | hook 规则（**必须带 `v:2` 才加载**，见坑 5） |
| `tools.json` | 自定义 JS 工具 |
| `booting` | 启动标记，20 秒后自动删；下次启动还在 = 上次崩了 |

路径含容器 UUID，每次重装 app 都会变。**不要硬编码**，用 `/api/info` 的 `home`
或 `app.paths` 工具动态取。

## 崩溃循环保护（三层）

1. **规则版本迁移**：`hooks.json` 里每条规则带 `v:2`，旧版（没有 v）直接跳过。
2. **boot 标记**：启动写 `booting`，20 秒后删。下次启动发现还在 → 判定上次崩了 →
   把 `hooks.json` 移到 `.bad`，跳过恢复。
3. **默认不落盘**：`/api/hook` 要显式加 `persist=1` 才写盘。调试期的 hook 重启即失效。

这套机制是被坑出来的，见坑 5。
